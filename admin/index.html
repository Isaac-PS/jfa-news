Painel administrativo

Entrar

Cole o token de acesso do GitHub. Ele fica guardado só neste navegador e nunca vai para o site. O passo a passo para gerar o token está no arquivo README do projeto.

Notícias

    Nova notícia

    0/160 Aparece no cartão da notícia. Se ficar em branco, usamos o início do texto.
    Deixe uma linha em branco entre um parágrafo e outro. Use os botões acima para destacar trechos e inserir links, imagens e vídeos.
    Prévia do texto
    JPG, PNG ou WebP. A imagem é reduzida automaticamente antes de ser enviada.

    Inserir link

    Se houver texto selecionado, ele vira o link.

    Inserir imagem

    JPG, PNG ou WebP. A imagem é reduzida e enviada ao site agora.
    Aparece como legenda e ajuda quem usa leitor de tela.
